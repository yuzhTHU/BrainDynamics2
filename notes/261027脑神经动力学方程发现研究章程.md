# 脑神经动力学方程发现：研究章程

更新日期：2026-10-09

## 最终目标

从 `data.npy` 的全皮层 activity traces、节点空间/脑区信息及 Awake/REM/NREM 标签中，建立能够泛化、可模拟、可解释的脑神经动力学方程和相应网络结构，并用它们回答：

1. 哪些慢时间尺度和低维群体状态主导观测动力学？
2. 自身记忆、全局共同驱动、区域耦合和细胞间稀疏耦合各贡献多少？
3. 动力学与网络结构如何随 Awake、REM、NREM 改变？
4. 哪些方程项具有稳健的预测价值，哪些可获得神经机制解释？
5. 模型能否重现长期统计、空间传播、同步和状态转换等涌现行为？

## 研究原则

- 严格区分潜在神经活动、未知 indicator/测量动力学、采集积分和测量噪声；在元数据确认前不预设为钙信号。
- 严格区分结构连接、功能连接、定向预测影响和干预意义上的有效连接。
- 先证明可辨识，再解释参数；先做负对照，再解释网络拓扑。
- 所有切分按连续时间段或完整状态 episode 进行，禁止随机帧泄漏。
- 报告节点级指标分布和跨 seed/episode 不确定性，不只报告展平相关。
- 每个复杂模型必须与 persistence、共享 AR、逐节点 AR、状态条件 AR 和全局均值模型比较。
- 方程发现采用预测、长期统计、稳定性、复杂度和机制一致性的多目标评价。

## 分阶段路线

### Phase 0：数据与观测过程审计

- 核验信号尺度、异常值、漂移、状态 episode、节点/脑区分布。
- 估计自相关、功率谱、有效记忆长度、低维度和区域共同活动。
- 向数据提供方确认 GCaMP、曝光、预处理、ROI 类型、动物/会话和细胞类型信息。

### Phase 1：可辨识性与强基线

- 在严格 blocked split 下复现 persistence、AR、TCN 等基线。
- 比较 self history、global context、region context、spatial neighbors 和 correlation neighbors 的增量预测信息。
- 通过合成神经活动 → 候选测量核（含可选钙核）→ 候选积分窗 → 4.146 Hz 采样，定量研究哪些参数可恢复。

### Phase 2：低维随机状态空间模型

- 以 25 个脑区均值及区域内潜在模态为状态。
- 比较 LDS、switching LDS、随机 neural ODE/SDE 和低秩动力系统。
- 显式加入观测核、状态条件参数和潜在共同输入。

### Phase 3：机制方程

- 区域级 Wilson–Cowan。
- E/I + 慢适应 neural-mass 模型。
- 泄露 + 饱和突触/增益调制模型。
- FHN/AdEx 只通过高频潜在模拟和显式观测模型比较，不直接把 activity trace 当膜电位。

### Phase 4：网络与方程联合发现

- 网络采用低秩全局项 + 稀疏区域/局部残差，而非完整 62130² 参数矩阵。
- 使用空间、脑区和解剖先验；以随机图、全连接图和节点置换为负对照。
- 在可辨识的候选库内做稀疏回归、符号回归或 Bayesian model comparison。

### Phase 5：模型证伪与系统洞察

- 短期预测、自由递推、长期分布、ACF/PSD、协方差谱和潜在流形。
- 状态驻留时间与转换、同步、事件触发空间图、传播方向和相关长度。
- 参数恢复、后验预测检查、跨 episode/状态/节点/区域泛化。
- 若获得光遗传、解剖或细胞类型数据，再验证因果连接和 E/I 身份。

## 当前关键假设

H1. 长历史模型的优势主要来自未知测量/采集滤波和慢共同驱动，而非单细胞确定性可预测性。

H2. 控制自身历史和全局低维活动后，特定细胞间图提供的增量预测信息较小。

H3. Awake、REM、NREM 需要 switching 或状态条件动力学；单一自治方程会混合不同机制。

H4. 区域级 E/I + 慢适应模型比逐细胞 FHN/AdEx 更符合 4.146 Hz 数据的可辨识尺度。

H5. 可解释网络应表现为低秩共同驱动与稀疏残差耦合的叠加。

## 成功标准

最终模型至少需要同时满足：

- 在完整 held-out episode 上超过强 AR/TCN 基线之一，而非只拟合训练数据；
- 在多个 seed 和节点子样本上稳定；
- 自由模拟保持有界并重现实测长期统计；
- 网络项通过随机图、全局均值和时间置换负对照；
- 方程复杂度足以解释数据但参数可辨识；
- 生物解释不超出采样率、观测模型和元数据所允许的范围。
