# 原始数据与视频同步审计

## 已确认事实

- 原始轨迹位于 `wholebrain_output_after_rejection.mat:/whole_trace_ori`，形状 `(28801, 62130)`、float32。当前 `data.npy` 是直接副本；随机 10,000 点逐值完全相等。
- 原始 `readme.txt` 将其描述为“发放率信息”，但没有单位、indicator、去卷积或基线校正说明。负值范围可到约 -39,556，因此本文档统一称为 activity trace，不把数值直接解释成 Hz。
- `valid_area.mat` 中的 `acs`、`names`、`ids`、`whole_center_2d_T` 与 `node_info.csv` 完全相同。
- `stimuli.mat` 包含 98 个 MATLAB 1-based 闭区间，完整且无缝覆盖 28,801 帧；重建后与 `time_info.csv` 完全相同。
- 标签由头皮 EEG 给出；未发现原始 EEG 波形文件，只有状态区间。

## 新发现的空间信息

`whole_center` 有四列整数，范围分别为：

1. 5–3274；
2. 2–4472；
3. 10–53；
4. 3–12。

原说明称原始文件包含 3D 坐标，因此前三列很可能是体数据坐标。投影二维坐标与第二列相关 0.995、与第一列负相关 -0.987，符合旋转/投影关系。第四列语义未知，可能是 ROI 尺度或其他提取参数，未获文档前不使用。

派生表保存在 `logs/scripts/audit_raw_source/initial/raw_node_geometry.csv`；没有修改原始 MAT。

## 视频同步

- `51.mp4`: H.264，640×480，约 30 fps，251,279 个声明帧，8376.13 s。
- 画面覆盖固定头小鼠的眼睛、鼻口和胡须，可提取运动、瞳孔和 REM 眼动协变量。
- 顶部区域存在周期性绿光。阈值化后得到单一连续脉冲列，脉冲数恰好为 **28,801**。
- 线性拟合候选神经帧索引 `k` 与视频时间：

  `t_video ≈ 13.58267 + 0.24117810 * k` 秒。

- 相应采样率为 **4.1463135 Hz**；首末脉冲跨度 6945.9667 s，与 `(28801-1)/fs` 一致。
- 时钟拟合残差标准差 26 ms，主要来自 30 fps 视频时间量化；相邻脉冲间隔为 7、8 或 9 个视频帧。
- 绿光高电平宽度中位数 3 个视频帧，即约 0.10 s，10–90% 为约 0.067–0.10 s。它可能对应曝光或一次体扫描的亮灯时间，但并非硬件说明书中的曝光参数。

## 对建模的影响

1. 全部秒轴改用 4.1463135 Hz。
2. 一帧为 0.24118 s；亚帧突触时延不可直接辨识。
3. 观测积分敏感性分析以 0.067–0.10 s 为核心范围，同时保留更宽范围作稳健性检查。
4. 视频特征现在按每个检测脉冲的实际时间插值到 28,801 个神经帧，而不是只应用一个固定 offset；后续可将面部运动、胡须和瞳孔作为共同输入 `u(t)`，检验网络边是否只是行为/觉醒混杂。
